# Mahiko Modpack

Enhance yourself with the world of magic!

The spells found in this modpack are divided up into five elements:

1. Fire
2. Water
3. Earth
4. Wind
5. Healing

Want to register your own element? Or, you have an idea for a spell, but don't see it listed?

Then, use the API provided by `mahiko_spells` to create your own!

## Obtaining Spells

- You must find and mine essence ore for essence fragments.
- Craft a spell table and spellguide for the spells' recipes.

## Tips & Tricks

- Stacking (or spamming) spells is encouraged.
- Moving a spell into another inventory (ex. from player to chest) is only possible if the cooldown on the spell is zero.
- Dying and leaving the game resets the cooldown for the spell.
	- Any unexpected shutdown or game crash may not. Use `/resetspell` to fix.
